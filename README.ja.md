# Paw World（パウ・ワールド）― なかまたちの冒険

[English / Українська](README.md) · [日本語版 PDF（18ページ）](books/Paw_World_Japanese_v1.0.pdf)

## 作品紹介

『Paw World』は、動物のなかまたちが力を合わせ、自然の中を旅しながら新しい世界を発見していく、子ども向けの創作絵物語です。友情や思いやり、冒険の楽しさを大切にし、物語の中にさまざまな学習の要素を取り入れています。

色鮮やかな森、花畑、山々、きらめく洞窟を舞台に、なかまたちは困っている友だちを助けたり、迷路やパズルに挑戦したりします。やがて数字や時間、暦の不思議に出会い、新しい冒険へと進んでいきます。

## 本書の特徴

- 動物のなかまたちと一緒に楽しめる、イラスト中心の冒険物語。
- 友情、思いやり、協力、好奇心をテーマにしたエピソード。
- 迷路、数字のパズル、チェスの課題などの参加型の学習要素。
- 二進法・八進法、マヤ暦など、数学や時間の概念への導入。
- 次の物語につながる結末。続編や教育コンテンツへの展開を構想しています。
