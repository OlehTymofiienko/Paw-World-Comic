# Book files / Файли книжок

Upload these **two PDFs** to this folder (their filenames must match exactly):

1. `Paw_World_Original_v1.0.pdf` — 18-page approved original.
2. `Paw_World_English_v1.0.pdf` — 18-page first English translated edition.

Download the prepared package from the ChatGPT conversation, unzip it and open `books/`. In GitHub, open this folder, select **Add file → Upload files**, drag the two PDF files, and commit the changes.

After uploading, check that each file opens and that SHA-256 checksums agree with the root `SHA256SUMS.txt`.

Не змінюйте назви PDF-файлів: посилання в головному README використовують саме ці шляхи.
